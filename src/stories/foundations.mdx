# Design Tokens

The entire visual language lives in `src/app/globals.css` as Tailwind v4
`@theme` tokens. Components consume utilities — **no hex values appear in
component code**.

## Color

| Token | Value | Role |
| --- | --- | --- |
| `ink-950` | `#0e0d0b` | Matte black — footer, hero grounds |
| `ink-900` | `#171512` | Deep surfaces, body text on light |
| `charcoal-800…500` | grays | Secondary dark, muted text |
| `cream-100` | `#faf7f2` | Warm white — default page ground |
| `cream-50` | `#fdfcf9` | Card surfaces |
| `tan-200…400` | tans | Quiet fills, rules, chips |
| `gold-500` | `#c19a52` | **Action accent** — fills behind dark text |
| `gold-700` | `#7f6128` | Gold **text** on light surfaces (AA-safe) |
| `gold-300` | `#dcc394` | Gold accents on dark surfaces |
| `success / warning / error / info` | muted hues | Feedback, with `-300` dark-surface variants |

**Contrast rule:** `gold-500` never carries text on light grounds — use
`gold-700`. On dark grounds use `gold-300`/`gold-400`.

## Typography

| Role | Face | Utility |
| --- | --- | --- |
| Display / headings | Playfair Display | `font-display` |
| Navigation / buttons / labels | Poppins | `font-nav` |
| Body | Inter | `font-sans` (default) |

Fluid display sizes: `text-display-xl / lg / md / sm` (clamp-based).
Tracking: `tracking-nav` (0.08em) for buttons/nav, `tracking-label`
(0.18em) for eyebrows.

## Elevation, radius, motion

- Shadows: `shadow-card`, `shadow-card-hover`, `shadow-overlay`, `shadow-gold-glow`
- Radius: `rounded-card` (1rem) · `rounded-field` (0.625rem) · `rounded-pill`
- Easing: `ease-premium` (default), `--ease-enter`, `--ease-exit`
- Durations: `--duration-fast/base/slow/reveal` CSS variables
- Z-index scale: `--z-header/drawer/modal/toast/tooltip`

## Accessibility tokens

- Global focus ring: 2px `gold-600`, 3px offset, on `:focus-visible`
- `prefers-reduced-motion`: all CSS animation/transition collapses globally;
  JS-driven motion checks `useReducedMotion()`
- Touch targets: buttons and rows are ≥ 44 px (`min-h-11` and up)
